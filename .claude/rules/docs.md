# Writing docs and READMEs

Follow `docs/style.md`. In short: contract first, concrete numbers with units, absolute
dates, no em dashes, no hype words, say plainly what is not supported. Code in a README
is quoted from `examples/`, which CI compiles; never type an example freehand.
An ADR is never rewritten after it is accepted: a change is a new ADR that supersedes it.
